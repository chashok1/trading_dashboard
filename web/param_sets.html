Parameter sets are versioned overlays of tunable thresholds / weights / sigmoid k&x0 produced by etl/ml_tune_thresholds.py. The active set overrides the base rule values at scoring time. With no active set the engine uses the values stored on each atomic rule. After activating or deactivating a set, run python -m etl.rebuild_rules to propagate it to the derived tables.
